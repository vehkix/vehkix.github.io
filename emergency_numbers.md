### National Helpline Numbers (India)

These numbers are standard across India for emergency and essential services.

| Service                         | Number     |
| :------------------------------ | :--------- |
| **Integrated Emergency Number** | **112**    |
| Police                          | 100        |
| Fire                            | 101        |
| Ambulance                       | 102        |
| National Ambulance Service      | 108        |
| Cyber Crime Helpline            | 1930       |
| Women Helpline                  | 181 / 1091 |
| Child Helpline                  | 1098       |
| National Consumer Helpline      | 1915       |
| Railway Security/Medical        | 139        |
| Tourist Helpline                | 1363       |
| Road Accident Helpline          | 1073       |

NHAI Helpline: 1033
